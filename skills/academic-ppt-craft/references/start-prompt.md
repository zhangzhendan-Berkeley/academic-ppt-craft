# 新课程启动 Prompt：系统学习与备课访谈

使用方法：将下面分隔线之后的内容完整发送给新 agent，同时提供 `academic-ppt-craft` 文件夹或压缩包。开头的信息可选填；不知道就留空，由 agent 先检查材料再追问。无需提前自己整理完整大纲、找齐论文或回答所有问题。

---

请使用 `$academic-ppt-craft`，担任这门新课程的备课合作者。先系统学习我提供的 skill 和范本，建立对教学要求、语言风格、审美及工程标准的具体理解，然后以类似“grill me”的方式，与我逐轮明确课程目标、边界、内容主线、详略和材料需求。

这里的“grill me”指有准备、有判断、能追问到底的备课访谈，不依赖你已安装一个同名 skill。不要只礼貌地问我想讲什么，再把回答拼成目录。你需要检查我的设想是否成立，发现缺口，给出有依据的选择，帮助我把课程想清楚。

我目前能提供的信息如下，空白项不代表没有要求：

- 暂定课程／讲次／主题：
- 听众及已学基础：
- 课时或授课时长：
- 已提供的文件／目录：
- 特别想讲的工作、任务或案例：
- 与其他讲次的关系：
- 本次已明确的其他要求：

## 一、先确定工作范围

当前任务是学习标准、开展备课访谈、盘点材料、进行支撑主线的初步调研，并形成可供审核的整体内容规划。先不要制作正式PPT、逐页正文或整套LaTeX工程。

不要仅凭“新课程”继承旧触觉课的标题、七节结构、USB任务、161页或50篇论文指标。需要继承的是教学逻辑、表达习惯、审美、模板执行方式和验收标准。

如果我后续明确批准主线、要求开始逐页制作，则继续进入已授权阶段，不重新启动整套问卷，也不额外索要已经给过的批准。

## 二、系统学习skill，不要只读入口

先定位并读取完整的 `academic-ppt-craft/SKILL.md`。如果只收到ZIP，将它解压到独立目录，保持附件和相对路径完整。不要覆盖我已有文件。

按以下顺序全文阅读规范，长文件分段读到末尾，不能以工具输出被截断的部分冒充全文：

1. `references/preferences.md`：识别长期要求、模板特定参数、课程案例及被替代的历史规则。
2. `references/teaching.md`、`references/writing.md`、`references/case-lessons.md`：学习内容组织、教师改句及历次被否决的原因。
3. `references/template.md`、`references/evidence.md`：学习真实模板对象、图文关系、视频、来源和证据标准。
4. `references/engineering.md`、`references/review.md`、`references/latex.md`：理解不同交付阶段和验收方式；阅读不等于现在就开始制作。
5. `references/intake.md`、`assets/course-brief.md`：学习逐轮访谈与材料分工。
6. `references/visual-composition.md`、`references/slide-reduction.md`、`references/examples.md`、`references/maintenance.md`：学习附件用途、复用边界和持续维护方法。

检查 `assets/attachment-manifest.json` 与 `assets/template-profile.json`，了解随包材料和模板对象的定位方式。脚本只在有实际检查或打包需要时执行，不为了显示工作量无目的地运行所有脚本。

发生冲突时，先区分最新用户要求、当前模板、旧范本示例与历史记录。不要同时保留互相矛盾的规则，也不要把自己的常用习惯写成我的要求。

## 三、实际看范本，不要只提取文字

请完成以下学习：

- **备课SOP**：全文阅读 `assets/course-sop.pdf` 的4页，理解学习顺序、必要基础、符号连续、原图证据和工程检查。
- **PPT模板**：逐页查看 `assets/ppt-template.pptx` 的15页，同时检查原生对象与格式。识别目录数字组合、段落项目符号、段内配色、正文／标题层级、参考文献和视频设置。第11、13页的案例组合与主线图可作为版式资源；正文仍遵守前面规定的字体、引用和媒体要求。
- **图文范例**：逐页查看 `assets/visual-combinations.pptx` 的6页，学习图名压线、共同外框、角标、侧线、色签和流程关系。若教师另给了可用的教学范本，再选择连续片段学习，不要求寻找本包未收录的历史课件。
- **工程范例**：查看 `assets/engineering-example.pdf` 的目录、导入、具有连续推导和图文证据的一段、章节过渡及结尾。选择的连续片段应足以理解其内容展开方式，记录实际页码。当前不要求为了访谈而逐字重读128页；后续制作母稿时按内容需要继续深入。不能将抽样阅读记成已通读全书。

如果当前工具无法渲染PPT，可以检查是否有PowerPoint、WPS或其他本地渲染方式，并从副本导出PDF。确实无法视觉检查时，明确记录已读文字／结构和未完成的视觉范围；不要宣称已经掌握实际排版。可以继续不依赖该限制的材料盘点，但不要开始需要视觉确认的正式排版。

范本用于学习，不是可以直接照搬的标准答案。范本旧框、旧视频格式、技术笔误或长段落，不覆盖我后来明确纠正的要求。内部保密文件不得上传外部服务或放进分享包。

## 四、用具体判断证明你学会了

不要给我长篇“已阅读、已理解、严格遵守”的承诺。建立一份简洁的学习记录，至少包含：

1. 实际读过哪些文件、看过哪些页面，哪些范围尚未完成。
2. 长期偏好、当前模板参数、旧课程专有内容分别是什么。
3. 从教学范本归纳至少三个具体设计判断，附文件与页码。例如某组连续页面为什么能讲清一个概念、某张图如何支撑正文、比较页怎样回收前面知识。
4. 从教师改句中归纳至少三个修改原则，区分教师原句与自己的建议例句。
5. 给出两个简短的自行改写示例，体现具体对象、条件、专业术语和明确结论，不要只换同义词，也不要编造研究结果。

你应能具体解释这些差别：

- 内容信息量充分，与每页塞满文字的差别。
- 专业且易懂，与删掉专业名词／背景的差别。
- 多图多视频，与给每页配一张无关图片的差别。
- 原生模板对象，与自己画一个看起来类似的形状的差别。
- 全讲目录、节内内容清单、节内回顾、节间高亮目录的不同用途。
- 论文提供证据，与按论文名单组织课程的差别。
- 编译和渲染成功，与学生能听懂、教师认可的差别。

学习记录保存到项目里；聊天只汇报关键理解与实际限制，不把全部规范复述给我。完成这一阶段后自行接着盘点新课材料并提出首轮问题，不停在“学习完成，是否继续”。

## 五、先检查现有材料，再列我需要准备什么

阅读新项目已有的说明、大纲、相邻讲次、旧稿、手改稿、论文、图片、视频和研究汇报。检查实际内容，不能仅凭文件名或PROGRESS中的记录认定存在或完成。

输出一张材料表，至少包含：材料名称、用途、现有文件或线索、缺失内容、负责方、当前状态、是否影响下一步。

分成三类：

1. **需要我提供或确认**：受众、课时、课程体系、内部研究资料、必须讲的内容、模板选择、授课身份、内部素材使用范围等。
2. **你能自行完成**：公开论文调研与下载、概念查证、实验对照查找、公开图片和视频检索、素材整理、方案比较等。
3. **可选补充**：有助于改进但不阻塞当前主线规划的材料。

每项说明具体需要什么，不要只写“提供素材”“提供大纲”。也不要把查论文、找图、找视频的工作全部交给我。

已经有指定模板或明确长期偏好的，直接沿用，不重新问我颜色、项目符号和文献格式。材料缺失时先推进可以独立完成的工作，只有影响关键判断的信息才提出问题。

## 六、进入逐轮深入的grill me访谈

每轮优先问一个核心问题，最多三个紧密相关的问题。根据我的回答调整后续问题，不把预设问卷从头念到尾，也不要一次甩出几十问。

提问要带着已经做过的分析：先简短说明你从材料看到了什么、现在有什么实质分歧，再问我的取舍。如果给选项，提供你推荐的方案及理由，同时允许我自由回答。

重点逐步弄清以下事项，已经知道的跳过：

### 课程定位和学生输入

- 这节课为什么需要单独存在？与前后讲次相比新增的知识是什么？
- 学生已有基础是什么，哪些术语和方法不能默认他们懂？
- 学完最应能解释、判断或应用哪三件事？“了解前沿”具体落在哪些能力上？
- 在给定课时里，什么值得讲透，什么适合集中科普，什么应留给其他课程？

### 主线和贯穿任务

- 全讲能否围绕一个清楚的问题组织，而不是多个热门技术拼盘？
- 是否存在适合贯穿的任务，能连接不同技术的作用？任务的起点、困难、反馈和完成标准是什么？
- 如果没有自然的单一任务，可以采用问题链或相关任务组，不要生硬塞入一个贯穿案例。
- 小节之间究竟是递进、并列比较还是汇合？下一节的必要性从哪里来？
- 哪些基础知识必须先讲，才能理解后面的模型、指标和实验？

### 内容取舍和研究案例

- 哪几项内容必须连续多页讲清，为什么值得花时间？
- 哪些成果适合承担原理解释，哪些适合证明任务收益，哪些只适合前沿展示？
- 有无任务图、方法说明、对照实验或消融，能支撑我想强调的结论？
- 只拿到宣传视频或公告的成果，应如何控制结论范围？
- 遇到后面课程才会介绍的热门技术，如何用一页技术导读建立最低背景，再讲本课的贡献？

### 可讲性与制作条件

- 教师熟悉哪些内容，哪些内容需要更扎实的解释资料？
- 哪些现象必须用视频表达，哪些需要原图、对比、动画或公式？
- 模板和授课环境是否明确，是否有字体或媒体方面的实际限制？
- 哪些内部材料可课堂展示，哪些仅本地学习，哪些不能打包？

不要只顺着我的想法说“很好”。如果我的目标太宽、与别的讲次重复、证据不足、贯穿任务不成立或课时不够，直接指出具体矛盾，提出可比较的解决方案。不要把审美主观判断包装成客观定律。

当我回答“都重要”“你决定”“还不确定”时，根据已知信息给出推荐结构和取舍理由，让我评价具体方案，不要原样重复问题。

每轮回答后，把确定的条件写入课程简报；区分“我明确确认”“文件证实”“你提出的假设”“仍待决定”。不要将我提出的一个思路立即当作已经批准的大纲。

## 七、调研与访谈交替推进

不必等所有问题回答完才做公开调研，也不要在主题尚未明确时下载一大堆无关文章。围绕正在形成的主线，先查足够支撑判断的代表性研究。

对拟进入课程的重点案例，至少弄清：什么任务、为什么难、输入输出、核心方法、实验设置、比较对象、结果含义、限制，以及有没有适合教学的图片或视频。

优先原始论文和作者公开材料；需要最新信息时实际联网核验。下载并保存读过的全文，登记真实阅读深度和来源。无法下载的列成方便我手动补齐的清单，不把“下载失败”放到课堂内容里。

不要用“指标提高所以更好”代替解释。要说明该指标反映什么能力、比较是否公平、结果支持到什么程度。没有证据的内容明确作为待验证设想，不能写成研究结论。

## 八、访谈需要收敛到可审核的方案

当教学对象、课时、边界、核心目标、主要内容取舍和素材条件足够明确时，停止重复提问，形成具体规划。无需等到每张图、每篇论文都找齐才规划主线。

请交付：

1. **课程简报**：已确认条件、工作假设、尚未解决但不阻塞规划的问题。
2. **材料准备与分工清单**：我需提供、你负责调研、可选补充及实际状态。
3. **整讲内容主线**：暂定标题、核心问题、引入、模块顺序、贯穿任务或问题链、实质总结与结束思路。
4. **小节内容和衔接表**：每节具体讲什么、解决什么、需要哪些先验、详略与大致时间、前后如何连接、准备采用什么证据和视频。
5. **代表性案例说明**：用少量具体研究让方案可判断，不只是抽象章名和口号。
6. **主线审阅文件**：优先几页清楚的整体规划PDF及可维护源文件，不提前扩写成逐页全稿。如果我另有格式要求则遵从。

需要我审核时，给出已经整理好的具体方案和真正需要决定的少数取舍。不要停在“是否需要我做一个大纲”。主线未获批准前不制作正式课件；我批准后进入制作阶段，继续遵守skill中的全部细节标准。

## 九、持续维护与沟通

在项目中维护轻量、真实的学习记录、课程简报、材料台账、主线和进度。沿用现有文件结构，不为记录而制造大量重复文档。中断后先读实际状态继续，不从头询问。

我对表达、格式和审美的新纠正，如果具有长期适用性，更新到skill相应主题并消除旧冲突；如果只是本课程内容选择，写入课程简报。不要只口头说记住，也不要把一次局部选择变成所有新课都必须遵守的规则。

现在请开始实际读取skill和附件。学习过程中简短汇报关键发现，完成必要学习后给出材料盘点和第一轮最关键的问题；不要仅回复工作计划或能力确认。
