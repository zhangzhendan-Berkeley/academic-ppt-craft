# 学术课件制作与备课访谈

让第一次听的学生理解任务、概念与证据，让教师可以直接讲、继续改。本skill来自多轮真实课件审校；它提供详细做法，但不保证一次生成即达到授课质量。

## 接手任务

1. 读取本入口与[配置与范围](references/preferences.md)，再读当前项目说明、实际文件和教师改稿。不能把旧进度当作现有成果。
2. 确定阶段：备课访谈、主线规划、LaTeX工程、正式PPT或局部修改。已有明确制作授权就继续，不重启访谈或索要重复审批。
3. 新课程按[访谈](references/intake.md)盘点材料，列出“已有／教师提供／agent可调研”，每轮追问1–3个会改变教学设计的问题。
4. 制作前读[教学设计](references/teaching.md)、[课堂语言](references/writing.md)和[模板规格](references/template.md)；涉及材料时读[素材与证据](references/evidence.md)。范例只按任务相关部分学习，不盲目搬用主题或全部附件。
5. 用[课程简报](assets/course-brief.md)记录本次选定的受众、目标、深度、模板、播放环境与公开范围。没有新模板时可采用随包模板作为起点；须替换原授课身份。

## 教学与内容

- 顺序来自知识依赖和任务进程，不按论文A、B、C罗列。每节交代上一节提供了什么、还缺什么；并列技术说明比较维度。
- 任务背景、困难、方法作用、首次术语和评价指标，在用于论证之前出现在学生可见页面。必要解释不能只放备注。
- 重点案例可连续多页展开；前沿用必要导读讲清新能力，不在这一讲重讲后续课程的完整推导。公式新符号先定义，同一对象跨页含义一致。
- 中文短句说明事实、关系、条件和结论。保留专业术语，首次必要时中文（English）。避免机械“从……到……：口号”和空泛“提升／赋能”；不要把教学写成论文汇报。
- 原图说明研究结果，任务视频解释动作和过程。展示消融前交代任务、输入、对照改变什么、指标方向和结果边界。代表性成功视频不能冒充成功率。

## 模板与美观

- 指定模板看原生对象和实际渲染：目录数字复制原组合，项目符号继承段落样式，不能用自画形状假冒。正文、表格、公式保持可编辑，不能整页截图充当PPT。
- 句内强调概念、差别和结论，普通文字保留黑色；示例配置用深蓝与深红。不能全黑、整段涂色或把全部概念刷蓝。
- 按内容选择大图、局部、比较、步骤与视频组合；学习[图文组合](references/visual-composition.md)。粗框与白底图名压线、角标、侧线、色签各有用途，不全稿套同一边框。
- 浅底色与深边框采用协调色系，避免红框蓝底／绿底。目录条目保持足够净间隙，原数字与标题整组移动；不能靠缩字扩大间距。
- 复杂证据图优先放大、拆图或拆页；保留坐标、图例与关键条件，裁掉无关英文caption。图名贴近实际图像并对齐。
- 先搜作者原图和合适的真实插图；需要原创说明插画时可调用可用的图片生成工具。不能编造实验证据；不要以粗糙程序矢量插画凑数。准确图表、公式、模板原组件和信息关系图可原生制作。

## 媒体、篇幅和交付

- 动作、接触、恢复、时序变化等内容优先使用对应视频。同一视频可在不同教学节点复用。转码、剪辑、倍速和来源登记；具体容器由播放环境决定，随包示例使用WMV。
- 视频须在实际软件试播，检查自动启动、多视频先后和时间推进。PDF是静态审阅件，不能替代视频播放验证。
- 资料来源保留在备注和资源记录。示例配置的页底只列文章引用，其他来源进备注；新模板可另行确定显示方式。
- 需要精简时读[篇幅取舍](references/slide-reduction.md)。只要建议就不删页；提供具体页码、合并内容、保留知识和净减少数。
- 保留教师实际手改原件；基于真实保存文件修订。交付可编辑PPT、审阅PDF、必要工程和验证范围；编译通过不等于教师认可。

## 学习资源与配置

[资源指南](references/examples.md)附15页模板、4页SOP、128页工程范例及原生组合练习。模板身份、章节数、固定字号、WMV、非互动课堂均属于[示例配置](references/preferences.md)，不是所有课程的不可变标准。新教师选择MP4、互动或不同模板时按本次要求执行。

公开库不收录保密研究原件、教师备份或私人项目成果。资源公开使用范围见[附件登记](assets/attachment-manifest.json)；资料内第三方内容不因仓库开放而自动改成开源许可。
